# Pages annotées à la main (feuille de route 2.7)

Une page par fichier : le contexte (l'annonce qu'on suppose), les huit réponses attendues aux
questions du jugement (`jugement.ts`), et pour chacune la raison lisible. Écrites le
2026-09-20 par kabylesystem (avec Claude), **à faire relire par un media buyer** : une
justification qu'il conteste se corrige ici, et le score bouge.

`npm run brain:eval` rejoue le jugement sur chaque page et compare : accord par question, par
page, et la liste des désaccords. Le dernier résultat est dans `dernier-resultat.json`.
